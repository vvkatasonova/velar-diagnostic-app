# Synthetic Sample Case

`Northstar Home Services (Sample)` exists only to demonstrate the complete product flow.

It is a **fixture**, not a real audit and not hidden AI output. The sample values are stored in `sample_case.py` and are based on a fictional scenario used to test the methodology.

The sample demonstrates:

- a client profile and baseline metrics;
- a manually selected Sales primary constraint;
- confirmed / not-present findings;
- causal roles (Root Cause → Contributing Cause → Symptom);
- protected strengths;
- a phased roadmap;
- report generation.

Keeping sample data in a separate fixture is intentional: production logic remains independent from demonstration content.
